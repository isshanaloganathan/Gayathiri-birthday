GAYU BIRTHDAY DELUXE WEBSITE
=============================
Files:
- index.html      Home
- about.html      About
- memories.html   Photo memories (18 photos, original portrait/landscape proportions)
- note.html       Birthday note
- surprise.html   Interactive gift box + confetti + surprise photo
- style.css       Elegant pink aesthetic
- script.js       Gift/confetti interactions
- images/         All 18 supplied photos

To preview:
1. Extract the ZIP.
2. Double-click index.html.
3. Keep the whole folder together.

To publish:
Upload the complete folder to a static web host (for example GitHub Pages), then make a QR code from the published URL.
